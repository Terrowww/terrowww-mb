> **Первую установку делай через SAI**, иначе Android заблокирует специальные возможности и Quick не сможет делать скриншоты. Все следующие обновления ставятся как обычно. Инструкция ниже: [Установка](#установка).

## Что это

Нажал на кружок, и приложение само снимает экран, отправляет снимок в Gemini и показывает ответ маленьким окошком. Переключаться между приложениями и фотографировать экран вручную не нужно.

- Работает на **твоём ключе Gemini** (бесплатный ключ даёт Google AI Studio)
- Без рекламы и регистрации
- Скриншот через специальные возможности, поэтому значка записи экрана нет
- Кружок можно сделать почти невидимым: прозрачность, размер, положение, вид букв
- Доступ по коду активации, привязанному к устройству

> [!WARNING]
> Каждое нажатие на кружок отправляет скриншот экрана в Gemini (Google). Не нажимай там, где на экране пароли, личные переписки или банковские данные. Ключ Gemini хранится на твоём телефоне.

## Установка

Нужно: Android 11 или новее, ключ Gemini API ([создать бесплатно](https://aistudio.google.com/apikey)) и код активации от автора.

**Почему SAI.** Приложение, установленное обычным способом (тап по скачанному APK), попадает под «ограниченные настройки»: Android не даёт включить сервис специальных возможностей. Quick делает скриншоты именно через него, поэтому без сервиса он не работает. Установщик SAI ставит приложение так, что этой блокировки обычно нет.

1. **Поставь SAI.** Скачай `SAI.apk` из [Releases](https://github.com/Terrowww/terrowww-mb/releases) и открой. Разреши установку из этого источника. SAI можно ставить обычным способом, блокировка касается только Quick. Это чужая программа с открытым кодом (автор Aefyr), я только положил её рядом.
2. **Скачай Quick.** Файл `Quick.apk` из того же раздела. Если телефон сразу предложит его установить, закрой окно: файл останется в «Загрузках».
3. **Установи через SAI.** Открой SAI, нажми **Install APKs** (по-русски может быть «Установить APK»), выбери `Quick.apk` и подтверди установку.
4. **Проверь.** Если сервис Quick включается в специальных возможностях без «Доступ запрещён», всё сделано правильно.

> [!TIP]
> **Обновления.** SAI нужен только для первой установки. Новые версии `Quick.apk` ставятся как обычно, поверх старой. Настройки, ключ, активация и право на специальные возможности сохраняются.

Если Quick уже был установлен обычным способом, удали его и поставь заново через SAI. Настройки, ключ и код придётся ввести снова. Удаляется приложение как обычно: «Настройки → Приложения → Quick».

## Первый запуск

1. **Активация.** В карточке «АКТИВАЦИЯ» нажми «Отправить ID» и пришли ID автору. Вставь полученный код и нажми «Активировать». Код работает только на этом устройстве, срок отсчитывается с момента ввода.
2. **Ключ Gemini.** Карточка «GEMINI»: вставь ключ, нажми «Загрузить список моделей», выбери модель. **[Какую модель лучше выбрать](#какие-модели-выбрать)**
3. **Включи сервис.** «КНОПКА» → «1. Включить сервис в спец. возможностях». В настройках Android найди Quick в установленных приложениях или загруженных службах и включи.
4. **Покажи кружок.** Вернись в Quick, нажми «2. Показать / скрыть кнопку». У правого края появится кружок.

<details>
<summary><b>Сервис не включается</b></summary>

1. **Настройки → Приложения → Quick**, меню **⋮** справа вверху, **«Разрешить ограниченные настройки»**. Потом снова включи сервис.
2. Нет такого пункта: переустанови Quick через SAI.
3. Крайний случай: выдать право через ADB с компьютера (нужна отладка по USB). Команды заменяют весь список включённых служб специальных возможностей, поэтому используй их, только если ничего не помогло:

```
adb shell settings put secure enabled_accessibility_services com.example.shotai/com.example.shotai.ShotService
adb shell settings put secure accessibility_enabled 1
```

## Какие модели выбрать

> [!NOTE]
> На момент написания (октябрь 2026) модели Gemini 3.6, 3.7 и 3.8 почти всё время недоступны из-за перегрузки уже около недели. Запрос к ним часто заканчивается ошибкой 503. Поэтому сейчас лучше брать 3.5.

| | Модель | Почему |
|---|---|---|
| Основная | **Gemini 3.5 Flash** | стабильно работает и точно отвечает |
| Запасная | **Gemini 3.5 Flash-Lite** | большой лимит запросов |

Со временем новые модели могут стабилизироваться. Чтобы проверить, выбери более новую в списке и сделай пару запросов: если часто приходит ошибка 503, вернись на 3.5.

</details>

## Как пользоваться

| Действие | Что происходит |
|---|---|
| Тап по кружку | Скриншот, запрос, ответ в окошке. Один тап = один запрос |
| Перетащить кружок или окошко | Меняется положение, оно запоминается |
| Удержать кружок | Прячет всё на заданное время |
| Тап по значку «1 / 2» | Переключает основную и запасную модель, во время запроса отменяет его |
| Щипок в окошке | Меняет размер окошка вместе с текстом |
| «—» в окошке | Сворачивает в маленький кружок, тап по нему возвращает ответ |
| Задержать палец на слове | Выделение: веди палец, оно растёт по словам |
| Копировать | Выделенное, а если ничего не выделено, весь ответ |
| ‹ N › | Последние 5 ответов |

**Значки у строки состояния.** «день» показывает остаток запросов за сутки (по тихоокеанскому времени, как у Google), «минута» остаток за минуту, «1 / 2» переключает модели. Ответ запасной модели начинается с «~».

**Буква на кружке.** T значит запрос идёт, R значит ответ готов и ждёт (режим «ответ свёрнутым»). На скриншот буква не попадает: она появляется уже после снимка.

## Возможности

| | |
|---|---|
| **Запросы** | Основная и запасная модель, отмена запроса, счётчики за день и за минуту, свой лимит для каждой модели |
| **Ответ** | Перетаскивание, размер щипком, сворачивание, выделение, копирование, история 5 ответов, автосворачивание по таймеру |
| **Режимы** | Ответ приходит свёрнутым, прятать всё удержанием кружка, защита от случайных нажатий после ответа |
| **Промпт** | Свой промпт со сбросом к стандартному, просьба отвечать без markdown и LaTeX |
| **Вид** | Прозрачность, размеры, цвета и положение всего, вид букв T и R, закрепление значков |
| **Вибрация** | На нажатие, ответ и ошибку, с настраиваемой силой |

## Настройки

Разделы раскрываются нажатием на заголовок. Всё сохраняется само. У каждого ползунка нажми на число справа, чтобы вписать своё значение.

<details>
<summary><b>Активация и кнопка</b></summary>

- **ID и код активации:** твой ID, «Копировать ID», «Отправить ID», поле для кода
- **Включить сервис** и **Показать / скрыть кнопку:** первые два шага запуска

</details>

<details>
<summary><b>Gemini</b></summary>

- **API-ключ** с aistudio.google.com/apikey
- **Загрузить список моделей.** Показываются только Flash и Flash-Lite
- **Модель** и **лимит запросов в день** для неё (лимит смотри в AI Studio, кнопка «Лимиты моих моделей»). Без лимита значок «день» показывает только число запросов
- **Запасная модель** включается значком «1 / 2». После перезапуска приложения снова основная

</details>

<details>
<summary><b>Промпт</b></summary>

- **Изменить:** что именно спрашивать у Gemini. «Стандартный» возвращает исходный
- **Просить Gemini без markdown и LaTeX:** формулы приходят обычными символами

</details>

<details>
<summary><b>Вибрация и скрытие</b></summary>

- **Вибрация** (нажал, ответ, ошибка) и **сила**, там же кнопки, чтобы почувствовать каждый тип
- **Прятать всё удержанием кружка:** сколько секунд держать и через сколько вернуть спрятанное
- **Сворачивать окошко через** N секунд (0 = никогда)

</details>

<details>
<summary><b>Ответ свёрнутым и индикатор</b></summary>

- **Ответ приходит свёрнутым:** окошко не выскакивает, ответ ждёт тапа по кружку
- **Буква на кружке** (T думает, R готово)
- **Вид буквы T / R:** прозрачность буквы, прозрачность кружка, пока на нём буква, размер, цвет (авто, белый, чёрный, серый), ореол. Кнопки «Показать T» и «Показать R» на 4 секунды показывают букву на настоящем кружке
- **Вибрация, когда ответ готов**

</details>

<details>
<summary><b>Кнопки в окошке ответа</b></summary>

- **Показать окошко для проверки:** тестовое окошко, в котором сразу видны все изменения вида
- **Размер** и **прозрачность** кнопок
- **История ‹ N ›** и **«Копировать»:** включаются и выключаются
- **«—»:** слева или справа (отключить нельзя)

</details>

<details>
<summary><b>Вид</b></summary>

- **Прозрачность:** кружок, значки «день» и «минута», «1 / 2», фон окошка, рамка, текст ответа, свёрнутый кружок, подсветка выделения
- **Размеры:** кружок, значки, текст ответа, размер окна, свёрнутый кружок
- **Что показывать:** значки «день» и «минута», светлый текст для тёмных экранов
- **Положение значков** по горизонтали и вертикали и «Закрепить значки»
- **Сбросить позиции** и **Сбросить всё** (ключ и промпт остаются)

</details>

## Частые вопросы

<details>
<summary><b>«Приложение подписано другим ключом»</b></summary>

Установлена версия, собранная не автором. Скачай `Quick.apk` из [Releases](https://github.com/Terrowww/terrowww-mb/releases).

</details>

<details>
<summary><b>«Срок истёк» или «Код не подходит»</b></summary>

Нужен новый код: отправь автору свой ID ещё раз.

</details>

<details>
<summary><b>«Нет API-ключа» или ошибка запроса</b></summary>

Проверь ключ в карточке «GEMINI». Ошибки 503 и 429 значат, что модель перегружена или закончился лимит: подожди или переключись на запасную модель значком «1 / 2».

</details>

<details>
<summary><b>Скриншот не делается</b></summary>

Проверь, что сервис Quick включён в специальных возможностях и что кружок показан.

</details>

<details>
<summary><b>Кружок слишком заметен</b></summary>

Уменьши прозрачность: «ВИД → Прозрачность → Кружок» и «Вид буквы T / R».

</details>

<details>
<summary><b>Куда уходят данные</b></summary>

Скриншот и промпт отправляются только в Gemini API Google, с твоим ключом.

</details>
